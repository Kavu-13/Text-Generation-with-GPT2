# GPT-2 Fine-Tuning with Hugging Face Transformers

This repository contains a Google Colab notebook for fine-tuning OpenAI’s **GPT-2** model on a **custom text dataset** using the Hugging Face `transformers` library.  

---

## 🚀 Features
- Fine-tune GPT-2 (`gpt2`, `gpt2-medium`, `gpt2-large`, etc.) on your own text.
- Upload and train on a custom `.txt` dataset in Colab.
- Uses Hugging Face `Trainer` API for easy training.
- Save and reload the fine-tuned model for text generation.
- Generate text completions from a prompt.
